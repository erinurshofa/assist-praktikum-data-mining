BAB I: INTUISI DASAR

🕵️ Menjadi "Detektif Data"

Data Mining adalah proses menemukan pola, tren, dan pengetahuan tersembunyi dari tumpukan data berukuran raksasa. Tanpa analisis, data hanyalah tumpukan angka mati.

💡 Analogi Popok Bayi & Kopi Kaleng:
Sebuah supermarket menemukan pola menarik: setiap hari Jumat sore, para ayah muda yang membeli popok bayi 80% juga membeli minuman kopi kaleng. Dengan memindahkan rak kopi ke sebelah rak popok, omset toko langsung naik pesat! Inilah yang disebut "Knowledge Discovery" (menemukan emas dari tumpukan data).

📊 Eksplorasi Data dengan Pandas

2.1 Membuat DataFrame Sederhana

Mengubah data mentah menjadi bentuk tabel dua dimensi lengkap dengan nama kolom dan indeks baris.

💡 Analogi Pemula:
Ibarat mengetik daftar nama dan nilai di kertas buram, lalu dengan perintah pd.DataFrame() kertas itu disulap jadi lembar Excel yang rapi dan siap dihitung.
2_1_membuat_dataframe.py 
import pandas as pd
import numpy as np

# Membuat DataFrame dari data nilai mahasiswa
data = {
    "Nama"   : ["Andi", "Budi", "Citra", "Dewi", "Eko", "Fajar", "Gita"],
    "JK"     : ["L", "L", "P", "P", "L", "L", "P"],
    "Usia"   : [19, 20, 18, 21, 20, 19, 20],
    "UTS"    : [78, 85, 92, 60, 70, 88, 75],
    "UAS"    : [80, 88, 95, 65, 72, 84, 90]
}

df = pd.DataFrame(data)
print(df)

BAB IV: STATISTIK DASAR

📐 Memahami Angka Statistik

2.3 Ukuran Pemusatan: Mean vs Median

File proyek: 2_3_ukuran_pemusatan_data.py

💡 Analogi Sultan Masuk Warkop:
Jika ada 5 mahasiswa dengan uang saku 10rb lalu tiba-tiba Sultan masuk membawa 1 Miliar, Rata-rata (Mean) uang saku seisi warkop jadi 166 Juta per orang! (Angka ini palsu/bias). Tetapi Median (Nilai Tengah) tetap 13.500. Itulah alasan kenapa standar gaji selalu memakai Median!
2_3_ukuran_pemusatan_data.py 
print("Rata-rata UTS :", df["UTS"].mean())
print("Median UAS    :", df["UAS"].median())
print("Modus Usia    :\n", df["Usia"].mode())
print("Min UTS :", df["UTS"].min(), "| Max UTS :", df["UTS"].max())
Rata-rata UTS : 78.28571428571429 Median UAS : 84.0 Modus Usia : 20 Min UTS : 60 | Max UTS : 92

2.4 Ukuran Penyebaran (Dispersion): Simpangan Baku

File proyek: 2_4_ukuran_penyebaran_data.py

Simpangan baku (std) mengukur kekompakan/keseragaman data. Makin kecil angkanya, data makin seragam dan tidak jomplang.

2_4_ukuran_penyebaran_data.py 
rentang = df["UTS"].max() - df["UTS"].min()
print("Rentang UTS        :", rentang)
print("Varians UTS        :", df["UTS"].var())
print("Simpangan baku UTS :", df["UTS"].std())
print("Kuartil UTS (Q1, Q2, Q3):\n", df["UTS"].quantile([0.25, 0.50, 0.75]))
Rentang UTS : 32 Varians UTS : 123.57142857142857 Simpangan baku UTS : 11.116268644263172

import matplotlib.pyplot as plt

bulan     = ["Jan", "Feb", "Mar", "Apr", "Mei", "Jun", "Jul"]

Garis biru menunjukkan arah pergerakan omset. Terlihat ada tren kenaikan umum (uptrend) dari Januari (12 juta) hingga puncaknya di Juli (25 juta). Sempat terjadi sedikit penurunan di bulan Juni (17 juta) sebelum melesat kembali. Grafik garis paling cocok untuk data deret waktu seperti ini!

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

data_tugas = {
    "Nama": ["Andi", "Budi", "Citra", "Dewi", "Eko", "Fajar", "Gita", "Hadi", "Indah", "Joko"],
    "JK": ["L", "L", "P", "P", "L", "L", "P", "L", "P", "L"],
    "Usia": [19, 20, 18, 21, 20, 19, 20, 22, 19, 21],
    "UTS": [78, 85, 92, 60, 70, 88, 75, 82, 90, 65],
    "UAS": [80, 88, 95, 65, 72, 84, 90, 85, 92, 70],
    "Absensi": [85, 90, 95, 70, 75, 90, 85, 88, 95, 72]
}

df_tugas = pd.DataFrame(data_tugas)
print(df_tugas.describe())

# Uji Korelasi Absensi vs UAS:
korelasi = df_tugas["Absensi"].corr(df_tugas["UAS"])
print(f"Korelasi Absensi & UAS: {korelasi:.4f}") # Output: 0.9519
